# menuswap-legal

Public legal pages for **Swapit** (App Store / Play Store privacy policy URL).

## Live URL (after GitHub Pages is on)

https://shahramalvi.github.io/menuswap-legal/privacy/

## Enable GitHub Pages

1. Open https://github.com/shahramalvi/menuswap-legal/settings/pages
2. **Source**: Deploy from a branch
3. **Branch**: `main` / `/ (root)`
4. Save

Use that privacy URL in App Store Connect and in the app’s `PRIVACY_URL`.
